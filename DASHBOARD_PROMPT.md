# Claude Code Prompt — WhatsApp AI Agent Dashboard

## CONTEXT

You are building a production dashboard for a WhatsApp AI agent SaaS product called **Agente** (working name). Each business client (furniture stores, law firms, doctors, etc.) logs in and manages their own WhatsApp AI bot from this dashboard.

The backend is a **FastAPI Python service** already running on Railway. You will build the frontend as a **single HTML file** (`dashboard.html`) served by FastAPI at the `/dashboard` route, plus a CSS file (`dashboard.css`) and a JS file (`dashboard.js`). All three files go into the `/static` folder of the FastAPI project.

The frontend communicates with the FastAPI backend via standard `fetch()` API calls. No React, no build step, no npm. Vanilla HTML + CSS + JavaScript only.

## DESIGN DIRECTION — READ THIS CAREFULLY

### Aesthetic: Quiet Luxury / Editorial Minimalism

Think: a premium Brazilian financial platform crossed with a European luxury brand identity. NOT a startup SaaS dashboard. NOT Material Design. NOT shadcn/ui defaults.

The one thing someone must remember about this dashboard: **it feels like it was built by a design studio, not generated by an AI.**

### Color System (use these exact CSS variables, do not deviate)

```css
:root {
  /* Surfaces */
  --bg-canvas:    #F7F4ED;   /* warm off-white page background */
  --bg-card:      #FFFFFF;   /* card surfaces */
  --bg-hover:     #F5EFE0;   /* champagne hover fill */

  /* Gold accent (ONLY for: active states, icons, dividers, key borders, chart line) */
  --gold:         #C9A84C;
  --gold-hover:   #A8893C;
  --gold-light:   #F5E6C8;   /* very light champagne for selected row tints */

  /* Text */
  --text-primary:   #1A1A1A;
  --text-secondary: #6B6B6B;
  --text-tertiary:  #9E9E9E;

  /* Borders */
  --border:       #ECE6DA;   /* hairline dividers */
  --border-dark:  #D4C9B0;

  /* Semantic — ONLY for status, never decorative */
  --green:   #3F7D5C;
  --amber:   #C99A2E;
  --red:     #B3261E;

  /* Sidebar (dark anchor option) */
  --sidebar-bg:     #1E1C19;
  --sidebar-text:   #D4C9B0;
  --sidebar-active: #C9A84C;

  /* Spacing / radius */
  --radius-card: 14px;
  --radius-pill: 999px;
  --shadow-card: 0 1px 3px rgba(26,26,26,0.06), 0 4px 12px rgba(26,26,26,0.04);
}
```

**CRITICAL color rules — enforce these without exception:**
- Gold (`--gold`) is NEVER used as text color on white backgrounds — WCAG contrast fails
- Gold is ONLY used as: active sidebar indicator, selected tab underline (2px), icon strokes, thin 1px borders, primary button fill (with `--text-primary` text, not white)
- No gradients anywhere except a subtle `--bg-canvas` noise texture
- No glassmorphism, no blur effects
- No purple, blue, teal, or cyan anywhere in the design

### Typography (import from Google Fonts)

```html
<link href="https://fonts.googleapis.com/css2?family=Fraunces:ital,opsz,wght@0,9..144,300;0,9..144,400;0,9..144,500;1,9..144,300&family=Hanken+Grotesk:wght@300;400;500;600&display=swap" rel="stylesheet">
```

- **Fraunces** — page titles (h1), section headers (h2), KPI numbers. Set `font-optical-sizing: auto`. Use weight 300–400 for an elegant, not heavy, feel.
- **Hanken Grotesk** — everything else: labels, body text, table content, buttons, nav items
- **Tabular figures** — for all numbers in tables and KPI cards: `font-variant-numeric: tabular-nums`
- Type scale: 11px labels → 13px body → 15px UI text → 20px card headers (Fraunces) → 28px page title (Fraunces) → 40px KPI numbers (Fraunces, weight 300)

```

│                        │  ┌──────────────┐   │
│  [logo]                │  │ TOP BAR      │   │
```

- Sidebar: 240px, dark (`--sidebar-bg`), fixed position
- Main content: `margin-left: 240px`, `padding: 32px`
- Cards: `--bg-card`, `--radius-card`, `--shadow-card`, border: `1px solid var(--border)`
- COMMIT to either border OR shadow on cards — not both. Use the shadow version (shadow-card) with NO border for main content cards. Use hairline border with NO shadow for table rows and subtle containers.

### What makes this NOT look AI-generated

**These are non-negotiable implementation details:**

1. **Three states for every data component:**
   - Loading: skeleton placeholder (animated shimmer with `--gold-light`) matching the EXACT layout of the loaded state
   - Empty: illustration (SVG, simple geometric, warm tones) + one sentence in Portuguese + one CTA button
   - Error: inline amber banner + retry button

2. **Microstates on every interactive element:**
   - Hover: `transition: all 150ms ease` with subtle background shift to `--bg-hover`
   - Focus-visible: `outline: 2px solid var(--gold); outline-offset: 2px` — no default browser outline
   - Active (pressed): scale(0.98)
   - Disabled: opacity 0.4, cursor not-allowed

3. **Status pills** — muted, not rainbow:
   - Active/online: `background: #E8F2EC; color: var(--green)` — small dot + text
   - Paused: `background: #FEF3E2; color: var(--amber)`
   - Error: `background: #FDECEA; color: var(--red)`

4. **Skeleton loaders** — not spinners. Build a `shimmer` keyframe animation:
   ```css
   @keyframes shimmer {
     0% { background-position: -200% 0; }
     100% { background-position: 200% 0; }
   }
   .skeleton {
     background: linear-gradient(90deg, var(--border) 25%, var(--gold-light) 50%, var(--border) 75%);
     background-size: 200% 100%;
     animation: shimmer 1.5s infinite;
     border-radius: 4px;
   }
   ```

5. **Real empty states** — when a table is empty, don't show "No data." Show:
   - A simple SVG illustration (geometric, warm tones — a chat bubble, a grid, etc.)
   - One line: "Nenhuma conversa ainda." or "Catálogo vazio. Adicione seu primeiro produto."
   - A gold-bordered CTA button

6. **Motion discipline:**
   - Page/section transition: `opacity 0→1, translateY 8px→0` over 300ms
   - Hover: 150ms
   - Modal open: scale(0.96)→scale(1), opacity 0→1, 200ms
   - Respect `@media (prefers-reduced-motion: reduce)` — disable all animations

7. **No placeholder copy** — use real Portuguese content:
   - Business name: "Móveis Viana" or "Clínica Dr. Silva"
   - Phone: "(47) 99999-8888"
   - Numbers: Brazilian format R$1.234,56

## PAGES AND FEATURES TO BUILD

### 1. Login Page (`/login`)
Separate from the dashboard. Clean, centered, branded.
- Logo + "Agente" wordmark (Fraunces, weight 300, gold `--gold`)
- Subtitle: "Gerencie seu assistente no WhatsApp"
- Email + password inputs (styled, no default browser look)
- "Entrar" primary button (gold fill, dark text, `--radius-pill`)
- Language toggle top-right: 🇧🇷 PT | EN
- No "sign up" — only existing clients log in (you onboard them manually)

### 2. Overview Page (default after login)

**Top bar:** breadcrumb showing current page + language toggle (PT | EN) + user avatar/name with dropdown (logout)

**KPI strip — 4 cards horizontally:**
| Card | Metric | Subtext |
|---|---|---|
| Conversas hoje | number | vs. ontem ▲/▼ % |
| Tempo médio de resposta | "4.2s" | "via IA" |
| Atendimentos humanos | number | "takeovers hoje" |
| Leads capturados | number | "mensagens qualificadas" |

KPI numbers: Fraunces weight 300, 40px, `--text-primary`
Delta indicators: Hanken Grotesk 12px — green if positive, red if negative, amber if zero

**Conversations volume chart:** simple line chart (pure SVG, no library) showing last 7 days. Gold line (`--gold`), warm-toned axes, no gridlines except a subtle horizontal baseline.

**Recent conversations table:** last 10 conversations.
Columns: Cliente | Última mensagem | Status (pill) | Horário | Ação (Abrir)
Row hover: `--bg-hover`

### 3. Conversations Page

**Left panel (320px):** conversation list — scrollable, each item shows:
- Phone number (formatted Brazilian style) or name if known
- Last message preview (truncated, 2 lines max)
- Timestamp (relative: "2min", "1h", "ontem")
- Status pill

**Right panel:** selected conversation detail
- Full message history (chat bubble style — customer messages left, AI responses right)
- Customer bubbles: `--bg-card` border, left-aligned
- AI bubbles: `--gold-light` background, right-aligned
- At top: customer phone/name, status, toggle switch for "IA ativada / IA pausada"
- Toggle switch: custom styled, gold when active

**Toggle switches** — custom CSS, no libraries:
```css
.toggle input:checked + .slider { background: var(--gold); }
.toggle .slider { transition: 0.2s; border-radius: var(--radius-pill); }
```

### 4. Products (Catalog) Page

**Top bar:** "Catálogo" heading + "Adicionar produto" button (gold border, `--bg-card` fill on default; gold fill on hover)

**Products table:**
Columns: # | Nome | Categoria | Preço | Estoque | Status | Ações
- Price column: right-aligned, tabular figures, R$ prefix
- Stock: number, right-aligned
- Status: "Ativo" (green pill) / "Inativo" (gray pill)
- Ações: edit icon button + delete icon button (appear on row hover)

**Add/Edit product modal:**
- Slides in from the right (drawer pattern, 480px wide)
- Backdrop: `rgba(26,26,26,0.4)` overlay
- Fields: Nome*, Categoria, Preço (R$), Estoque, Descrição (textarea, 4 rows), Especificações (textarea, 3 rows)
- Note in small text under Descrição: "Escreva descrições detalhadas para melhorar a busca por IA"
- Buttons: "Cancelar" (ghost) + "Salvar produto" (gold fill)
- Required field indicators: `*` in `--gold`

### 5. Navigation (sidebar items in order)
- Visão Geral (overview icon)
- Conversas (chat icon)
- Catálogo (grid icon)
- ─── (hairline divider)
- Configurações (settings icon — build placeholder page, "Em breve")

Active item: gold left border (3px), gold text color, `--bg-hover` background

## EXPLICIT DON'T LIST (enforce strictly)

These patterns will be rejected and rebuilt:

- ❌ Inter or Roboto as body font
- ❌ Any shade of purple, blue, or teal
- ❌ Gradient text on any element
- ❌ Colored side-border on rounded cards ("side-tab cards")
- ❌ Cards nested inside cards inside cards
- ❌ Glassmorphism or backdrop-filter blur
- ❌ Thick shadow (box-shadow spread > 24px)
- ❌ Hairline border AND soft shadow on the same element
- ❌ Over-rounded cards (border-radius > 16px on cards)
- ❌ Spinner loading states (use skeleton loaders instead)
- ❌ "No data available" as empty state (use designed empty states)
- ❌ Generic placeholder names (John Doe, Lorem ipsum)
- ❌ SaaS clichés in copy ("supercharge", "streamline", "empower")
- ❌ Equal 3-column card grids everywhere
- ❌ Icon + heading + paragraph stacked feature cards
- ❌ Pure white `#FFFFFF` as page canvas (use `--bg-canvas` `#F7F4ED`)
- ❌ Pure black `#000000` for text (use `--text-primary` `#1A1A1A`)
